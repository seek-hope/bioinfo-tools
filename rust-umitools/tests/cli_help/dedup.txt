Deduplicate reads grouped by UMI

Usage: rust-umitools dedup [OPTIONS] --stdin <FILE>

Options:
  -I, --stdin <FILE>
          Input file: BAM, or SAM when the name ends in .sam (- for stdin) [alias: --input]
  -S, --stdout <FILE>
          Output file; the format depends on the command (- for stdout) [alias: --output]
  -L, --log <FILE>
          Log file (defaults to stderr)
      --method <METHOD>
          Merge method: unique, percentile, cluster, adjacency, directional [default: directional]
      --edit-distance-threshold <THRESHOLD>
          Maximum Hamming distance between UMIs in a cluster [default: 1]
      --extract-umi-method <EXTRACT_UMI_METHOD>
          Where the UMI comes from: read_id, tag, umis [default: read_id]
      --umi-tag <UMI_TAG>
          UMI tag when --extract-umi-method=tag [default: RX]
      --verbose
          Print detailed build information together with --version
      --umi-separator <UMI_SEPARATOR>
          Separator for the UMI in the read name [default: _]
      --umi-tag-split <UMI_TAG_SPLIT>
          Split the UMI tag on this string and keep the first part
      --umi-tag-delim <UMI_TAG_DELIM>
          Remove this string from the UMI tag
      --cell-tag <CELL_TAG>
          Cell barcode tag (used with --per-cell) [default: CB]
      --per-cell
          Group by cell barcode as well as UMI
      --random-seed <RANDOM_SEED>
          Seed for the representative read draw [default: 0]
      --representative <REPRESENTATIVE>
          Representative read strategy: upstream, stable [default: upstream]
      --soft-clip-threshold <SOFT_CLIP_THRESHOLD>
          Soft clip length above which a read counts as spliced [default: 4]
      --spliced-is-unique
          Treat spliced reads as unique
      --ignore-tlen
          Ignore the template length when grouping
      --read-length
          Include the read length in the bundle key
      --mapping-quality <MAPPING_QUALITY>
          Discard reads below this MAPQ
      --multimapping-detection-method <DETECTION_METHOD>
          Multimapping detection tag: NH, X0 or XT
      --add-pg
          Append a @PG provenance record (changes the output bytes)
      --threads <THREADS>
          Worker threads
      --memory-limit <MEMORY_LIMIT>
          Memory budget, e.g. 4GiB
      --tmpdir <TMPDIR>
          Directory for temporary files
      --quiet
          Suppress informational output; errors are still printed
      --progress <MODE>
          Progress reporting: auto (terminal only), on, off [default: auto]
      --summary-json <FILE>
          Write a machine readable run summary to this file
      --sort-strategy <MODE>
          Sort strategy: auto, low-memory, high-throughput [default: auto]
      --reference <FASTA>
          Reference FASTA for CRAM input or output
      --compresslevel <COMPRESSLEVEL>
          BAM compression level (0-9; 0 stores uncompressed blocks) [default: 1]
      --paired
          Keep read pairs together
      --no-sort-output
          Write the output in processing order instead of coordinate order
      --output-stats <OUTPUT_STATS>
          Write per run statistics into this prefix (rejected: null model not implemented)
      --unpaired-reads <UNPAIRED_READS>
          What to do with read1s whose mate is not in the BAM: use, discard, output [default: use]
      --unmapped-reads <UNMAPPED_READS>
          What to do when the mate is unmapped: discard, output, use [default: discard]
      --chimeric-pairs <CHIMERIC_PAIRS>
          What to do with chimeric pairs: use, discard, output [default: use]
      --per-gene
          Group by gene instead of by position (requires --gene-tag)
      --gene-tag <GENE_TAG>
          Gene tag when --per-gene is used
      --buffer-whole-contig
          Buffer a whole contig before clustering (upstream compatibility)
      --chrom <CHROM>
          Restrict processing to one contig
      --subset <SUBSET>
          Keep each read with this probability (0 < p <= 1)
      --filter-umi
          Discard clusters whose top UMI is not in --umi-whitelist
      --umi-whitelist <FILE>
          Accepted UMIs, one per line (first column); required by --filter-umi
      --umi-whitelist-paired <FILE>
          Read2 whitelist; combined with --umi-whitelist as a cartesian product
      --gene-transcript-map <GENE_TRANSCRIPT_MAP>
          Gene to transcript map (count --per-contig only; dedup rejects it)
  -h, --help
          Print help

EXAMPLES:
  rust-umitools dedup -I in.bam -S out.bam
  rust-umitools dedup -I in.bam -S out.bam --paired --random-seed 1
  rust-umitools dedup -I in.bam -S out.bam --extract-umi-method=tag --umi-tag=RX

NOTES:
  Output is coordinate sorted by default; --no-sort-output keeps processing order.
  --add-pg appends a provenance @PG line and therefore changes the output bytes.
  Unsupported options fail before any output file is created.
