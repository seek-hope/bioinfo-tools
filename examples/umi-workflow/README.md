# UMI workflow consumer smoke

This example is a **synthetic consumer smoke**, not a biological result. It
demonstrates how the shipped CLIs compose in one pipeline:

```text
FASTQ -> trim -> QC -> alignment (or a pre-aligned fixture) -> coordinate sort/index
      -> UMI dedup -> UMI count -> MultiQC
```

The fixture stores the UMI in the `UB` tag and the gene assignment in `GX`. The
pre-aligned SAM is generated by `make_fixture.py`; it is **not** the output of an
aligner and must not be presented as one. For a real library, choose the
trimming/UMI-extraction order from the library protocol; do not copy this order
blindly.

## Quick start

Build the binaries once:

```bash
cargo build --release --workspace --bins --locked
```

Run the synthetic path:

```bash
MODE=prebuilt bash examples/umi-workflow/run.sh
```

Use a real aligner and reference:

```bash
MODE=align ALIGNER=bwa REF=/path/genome.fa bash examples/umi-workflow/run.sh
# or
MODE=align ALIGNER=minimap2 REF=/path/genome.fa bash examples/umi-workflow/run.sh
```

If `MODE=align` is selected and the aligner/reference is unavailable, the script
exits 3 with a clear message. It never fabricates an alignment in that mode.

## Inputs

- `make_fixture.py` deterministically creates:
  - `fixtures/reads.fastq` — 240 reads, adapter in every tenth read;
  - `fixtures/aligned.sam` — synthetic pre-aligned records with `UB` and `GX`;
  - `fixtures/reference.fa` — two synthetic 2 kb contigs.
- `samplesheet.csv` records the sample, FASTQ, reference, aligner/mode and the tag
  names for a workflow engine. The shell runner does not parse the sheet.

## Outputs

`OUT` defaults to `examples/umi-workflow/out`:

| Path | Producer |
| --- | --- |
| `trimmed.fastq.gz` | `rust-cutadapt` |
| `qc/reads_fastqc/fastqc_data.txt` | `rust-fastqc` |
| `aligned.sam` / `aligned.bam` | `MODE=align` or synthetic fixture / `rust-bam view` |
| `aligned.sorted.bam` + `.bai` | `rust-bam sort` / `rust-bam index` |
| `dedup.bam`, `dedup.sorted.bam` + `.bai` | `rust-umitools dedup` / `rust-bam` |
| `counts.tsv` | `rust-umitools count --per-gene --gene-tag GX` |
| `multiqc/multiqc_report.html` | optional MultiQC consumer check |

The smoke considers itself failed if `quickcheck` fails, `counts.tsv` is empty, or
the QC report is missing. If MultiQC is not installed it prints a skip; that is
not counted as a pass.

## Scope and limits

- The synthetic pre-aligned path is not evidence of alignment accuracy or a
  biological UMI result.
- No reference truth, variant, expression or differential-abundance claim is made.
- The example does not add a workflow engine; it is a shell consumer that a
  Snakemake/Nextflow wrapper can call.
- Missing aligner/reference is an explicit external blocker, not simulated.
