`bioinfo-tools` is a Rust workspace (snapshot commit `aaf4ba4`) providing five native command-line utilities (`rust-cutadapt`, `rust-umitools`, `rust-bam`, `rust-fastqc`, and `rust-fx`) and two shared libraries for high-throughput sequencing preprocessing, FASTX manipulation, post-alignment BAM processing, and quality control.

These tools run natively without invoking Python or Java at runtime. Upstream packages are only required when running cross-implementation verification tests or benchmarks. Rather than claiming drop-in replacement status across every upstream option, this repository targets an explicitly tracked workflow subset—covering adapter trimming, UMI extraction and deduplication, FASTX statistics and conversion, post-alignment BAM sorting/indexing/metrics, and sequence quality checks. The workspace does not include a sequence aligner; BAM workflows operate on outputs produced by external aligners.

## Tools and Upstream Baselines

| CLI Tool | Reference Baseline | Primary Scope in Typical Workflows | Parallelism & Runtime Notes |
| :--- | :--- | :--- | :--- |
| `rust-fx` | `SeqKit` 2.14.0, `fq` 0.12.0 | FASTA/FASTQ statistics, validation (`lint`), filtering, format conversion, and translation | Accepts `-j`, but currently executes single-threaded |
| `rust-cutadapt` | `cutadapt` 4.6 | Single- and paired-end adapter trimming, quality trimming, and read length filtering | Supports multi-threading via `-j` |
| `rust-fastqc` | `FastQC` 0.13.0 | 12-module QC statistics, custom limits/adapters/contaminants, and tabular report generation | Native execution; memory scales with read length, tiles, and distinct sequences |
| `rust-umitools` | `UMI-tools` 1.1.6 | UMI extraction into read headers, whitelist generation, and post-alignment `dedup`/`group`/`count` | Single-core graph/window deduplication on coordinate-sorted BAMs |
| `rust-bam` | `samtools` 1.24 | Post-alignment `view`, `sort`, `index`, `flagstat`, `depth`, and `coverage` | `sort` currently executes single-threaded |

## Building from Source

Building requires Rust `1.91` or newer (the repository toolchain is pinned to `1.99.1`). Existing release workflows under [`dist/README.md`](dist/README.md) only package `rust-cutadapt` and `rust-umitools`, and historical release binaries do not reflect the current workspace state. Example WorkflowThe commands below illustrate a typical preprocessing, QC, UMI extraction, and post-alignment deduplication pipeline (adjust -p to match your library UMI structure):Bash# 1. Inspect FASTQ statistics and validate formatting

# 6. Deduplicate coordinate-sorted BAM using default read_id UMI mode
rust-umitools dedup --random-seed 1 --compresslevel 6 -I sorted.bam -S dedup.bam

`bioinfo-tools` 是一个原生 Rust 生信工具工作区（当前源码快照 `aaf4ba4`），包含五个命令行工具（`rust-cutadapt`、`rust-umitools`、`rust-bam`、`rust-fastqc`、`rust-fx`）与两个共享库，用于高通量测序数据的接头修剪、FASTX 统计与转换、外部比对后 BAM 处理、UMI 去重以及质量控制。

所有工具在正常运行阶段均不调用 Python 或 Java 上游程序；仅在执行交叉正确性对照测试与性能基准测试时才需要安装上游环境。本仓库不宣称对上游所有参数做无差别替代，而是针对明确登记的常用生信工作流子集进行逐项验证。本仓库不包含序列比对器（aligner），BAM 与 UMI 去重流程均处理外部比对软件生成的 BAM 文件。
