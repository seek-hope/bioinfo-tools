Usage: fq <COMMAND>

Commands:
  filter     Filters a FASTQ file
  generate   Generates a random FASTQ file pair
  lint       Validates a FASTQ file pair
  subsample  Outputs a subset of records
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
